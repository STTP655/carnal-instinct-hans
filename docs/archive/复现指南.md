# 复现指南：从零复现当前汉化状态

> 前提：你拥有正版游戏，且已安装 UE4SS。仓库内**不含**任何游戏资产。

---

## 第 0 步：环境

| 需要 | 说明 |
|---|---|
| 游戏 | Carnal Instinct（UE 5.5 Shipping） |
| UE4SS | `v3.0.1-1176-g1ba38db4`，注入代理放 `Binaries/Win64/dwmapi.dll`，本体放 `Binaries/Win64/ue4ss/` |
| Python | 3.10+，装 `zstandard`（容器补丁脚本用） |
| retoc | 解包/打包 IoStore（打数据表补丁时需要） |

---

## 第 1 步：安装运行时 mod（覆盖大部分界面，不闪）

```powershell
.\tools\install_mod.ps1 -GamePath "<游戏>\Carnal_Instinct_UE5"
```

启动游戏，检查 `<游戏>\Binaries\Win64\ue4ss\UE4SS.log`：

```
[UIZh] UI 汉化 mod 已加载，映射表 2099 条
[UIZh] 双层轮询已启动：热区 700ms，全量每 12 轮
[UIZh] [HK3] hook 已挂载（第 1 次尝试）
```

此时主菜单、设置菜单、按钮与提示应为中文且**不闪烁**。

---

## 第 2 步：打数据表补丁（物品/技能/术语）

补丁脚本在你**自己的**容器上原地替换文本字段并更新 `SerialSize`：

```powershell
python .\tools\patch_containers.py `
  --game "<游戏>\Carnal_Instinct_UE5" `
  --jobs .\data\dt_jobs.json `
  --retoc "<retoc.exe 路径>"
```

脚本行为：

1. 备份原始 `.utoc/.ucas` 到 `--backup` 指定目录（默认与容器同级的 `_backup_<时间戳>`）；
2. 用 retoc 取出目标资产 → 在解压后的 chunk 内定位并替换英文字段 → 更新 `SerialSize` → 重新压缩受影响的块写回；
3. 输出每个资产替换条数与校验结果。

> 注意：脚本**只改文本字段**（DataTable 资产），不动蓝图 —— 蓝图的 `SerialSize` 不存在，任何写入都会导致游戏崩溃。

---

## 第 3 步：中文字形（如需）

UI 字体若不含 CJK 字形，中文会显示为方块。做法：

1. 取一份含 CJK 的开源字体（如 Noto Sans SC，SIL OFL 1.1）；
2. 生成游戏可用的 `RobotoRegular.ufont` 等 5 个字体资产；
3. 用 repak 打包成 `pakchunk1013-Windows.pak`（mount point `../../../`，V11，Fnv64BugFix）覆盖原文件。

---

## 第 4 步：验证

| 检查点 | 期望 |
|---|---|
| 主菜单 | 新游戏 / 继续 / 读取游戏 / 设置 / 退出游戏 |
| 设置-画面 | 画面 / 抗锯齿质量 / 窗口模式 / 垂直同步 |
| 物品提示 | 物品名与部分属性为中文；`Fire Resistance` 等 Slate-only 文本仍英文（已知限制） |
| 日志 | 无崩溃 dump 生成 |

---

## 第 5 步：扩充词条（可选）

1. 正常游玩，日志中的 `[MISS] 原文` 就是漏译清单；
2. 在 `mod/UIZh/scripts/main.lua` 里按批次追加词条（放在索引重建循环**之前**）：

```lua
local EXTRAxx = {
    ["English Text"] = "中文",
}
for k, v in pairs(EXTRAxx) do MAP[k] = v end
```

3. 重新运行 `install_mod.ps1` 并重启游戏即可生效。

---

## 回退

```powershell
.\tools\uninstall_mod.ps1 -GamePath "<游戏>\Carnal_Instinct_UE5"   # 撤掉运行时 mod
# 容器补丁：用第 2 步产生的 _backup_<时间戳> 覆盖回 Paks 目录
```
