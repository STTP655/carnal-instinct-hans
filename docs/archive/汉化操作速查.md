## 2. 证伪清单（一句话一条，别再试）

- **重建容器全部不行**：`retoc pack-raw`、`retoc to-zen`、`to-legacy→to-zen` 往返、`UnrealReZen` → 崩溃或格式不兼容。
- **新建/替换补丁容器**（`_P.pak`、`~mods`、编号 9999/1000、1014 号 utoc）→ 一律不被采用（IoStore 层压过 pak 层）。
- `.pak` 里放 legacy 资产 → 无效：游戏不从 .pak 读资产，**但会读其中的 locres**。
- 直接改 WB_* 蓝图的 uexp 字节（换长 / 等长替换）→ 崩溃，且方向多余（正文靠 locres 覆盖即可）。
- **全库无差别字节替换** → 有害：会把 StringTable 的 key 一起换掉，按键提示控件失效。
- 往 `pakchunk0` 的 `Game.locres` 注入 → 界面仍全英文（被 1013 号 pak 内同名文件遮蔽；有效的是 1013 内那份）。
- **枚举显示名兼作逻辑键的条目不能翻**：`E_Menus.Main` 曾译作「主」→ 环形菜单整块消失。
- 旧结论「全库 StringTableEntry 0 条」是错的：真正的是 **ht=0x0B**（ht=12 是 TextGenerator）。
- 松判据 `index < NameCount` 找 TableId → 9364 条伪解；必须要求 TableId 是含 `/` 与 `.` 的对象路径。
- 识别 FText 不加两道不变量（`Flags & ~0x1F == 0`、ns/key 至少一个非空）→ 420 条假阳性。
- Lua 轮询批量 `SetText`、用 Lua 遍历/写 UObject 属性 → 实测崩溃（`0xC0000005`）；**只有 hook 改参数安全**。
- Slate 渲染层文本（属性页标签、物品提示属性名）→ 不经 UMG `SetText`，需 C++ mod 钩 `STextBlock::SetText`。
- **pak 打包非确定性**（每次 SHA256 不同）→ 别拿 pak 的 SHA 判等，等价判据 = 解包后 locres 的 SHA256。

## 3. 一键脚本 / 回退

```powershell
$G = "K:\SteamLibrary\steamapps\common\CarnalInstinct\Carnal_Instinct_UE5"
.\tools\一键汉化.ps1 -GamePath $G -DryRun    # 干跑：只读检查 + 打印每一步，不写文件
.\tools\一键汉化.ps1 -GamePath $G            # 正式安装（游戏必须完全退出）
.\tools\一键汉化.ps1 -GamePath $G -SkipMod   # 只注入 locres，不装 mod
.\tools\回退汉化.ps1 -GamePath $G            # 回退（备份多于一份时按提示选序号）
.\tools\回退汉化.ps1 -GamePath $G -Latest -RemoveMod
```

安装流程：进程检测 → 探测 repak → 校验 `data\Game.locres.fix1` 的 SHA256 → 备份游戏 pak 到
`tools\backup\<时间戳>\`（含 `backup.json`）→ 解包游戏 pak → **只**替换其中的 `Game.locres` →
原参数 repak pack（`-m "../../../" --version V11 --compression Oodle -p 1048239905`）→ 解包复核
（文件清单一致 / 除 locres 外逐字节相同 / 包内 locres SHA 相符）→ 覆盖游戏 pak → 可选装 mod → 清理临时目录。
其它参数：`-RepakPath`、`-KeepTemp`、`-BackupRoot`。回退只还原 `.pak`；mod 默认只把 `enabled.txt` 改名关闭，`-RemoveMod` 才移走整个目录。

## 4. 常见任务

### 4.1 改一条译文（走 locres）
1. 用 `tools\locres_inject\locres_lib.py` 读 `data\Game.locres.fix1`，改目标 `(ns, key)` 的 value；
   **只改 value** —— `sourceStringHash`（对英文源算的 StrCrc32）与 `stringKeyHash` 一个字都不许动；
2. 存回 `data\Game.locres.fix1`，同步更新 `tools\一键汉化.ps1` 里的 `$ExpectedSha` 与本文档/README 里的哈希；
3. 重新打包并覆盖：`.\tools\一键汉化.ps1 -GamePath $G -SkipMod`（脚本自己会 repak + 四项复核）；
4. 若改的是工作区基线：在 `05_研究\bp_static\locres_experiment\` 改 → 重跑 `fix1_build.py`/`inject_full.py` → 再复制进发布仓库。

### 4.2 排查「某处还是英文」
先定位形态：工作区 `05_研究\bp_static\scan_alltext\ste_scan\check_terms.py --needles-file x.txt`
（给一批英文串，在全库 `.uexp` 里做字节级定位并判定形态），再按下表决定能不能翻：

| 形态 | 字节判据 | 能否翻 |
|---|---|---|
| 内联 FText（家族 A） | `u32 Flags(0/8) \| u8 ht \| FString ns \| FString key(32hex GUID) \| FString src` | ✅ 注入 locres（空 ns + GUID key） |
| StringTableEntry | `ht = 0x0B`，TableId 为对象路径（全库唯一表 `CommonTermsUI`） | ✅ 注入 locres |
| CultureInvariant | `flags=2`、`ht=0xFF`、`u32=1` | ❌ 运行时跳过查表，只能走 mod 或放弃 |
| 普通 FString / 裸串 | 前 4 字节 = 长度，无 FText 头 | ❌ 走 mod 词表 |
| 运行时拼装 | 原文由代码拼接 | ❌ 走 mod 词表（或放弃） |
| Slate-only | hook 日志 0 次命中、UMG 属性为空 | ❌ 需 C++ mod |

选实验词条前先确认该资产**在当前游戏版本实际挂载**（`WB_ProMainMenu` 是旧版菜单，当前主菜单是 `WB_T3_MainMenu`）。

### 4.3 补 mod 词条（不动 pak，最快见效）
1. 游戏日志里的 `[MISS] 原文` 就是漏译清单；
2. 在 `mod\UIZh\scripts\main.lua` 里按批次追加，放在索引重建循环**之前**：
   `local EXTRAxx = { ["English"] = "中文" }` 然后 `for k, v in pairs(EXTRAxx) do MAP[k] = v end`；
3. 重跑 `.\tools\一键汉化.ps1 -GamePath $G`（或 `tools\install_mod.ps1`）后重启游戏。

## 5. 铁律

1. **游戏必须完全退出**才能覆盖游戏文件（脚本会检测 `Carnal*` 进程）。
2. **改前必备份**：一键脚本每次安装先备份到 `tools\backup\<时间戳>\`；工作区改动备份到 `03_原始备份\`。
3. **绝不重建容器**，只做「原生容器内原地替换」；locres 也只是换掉 pak 内一个文件。
4. **只动 `.pak`**，不碰同目录 `.utoc/.ucas`（对话汉化容器，动了会毁掉 247 个文件的汉化）。
5. **枚举显示名兼作逻辑键的别翻**（如 `E_Menus.Main`），宁可保留英文。
6. **验证只认解包后的 locres SHA256**，不要用 pak 的 SHA256 判等。
7. 不要跑 Steam「验证文件完整性」；改译文后同步更新所有文档里的 SHA256。
